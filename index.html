cha-sysctlhardener

The Calibration Bench. A command line validator that reads a YAML or JSON configuration against a hardening policy written as a JSON schema and reports every setting that does not comply. Gauges are read against the standard, certificates are written, and the adjusting screws stay sealed: the report is the entire output.

The repository main.py
InputA configuration file and a policy file, both required
OutputEvery schema failure found, reported rather than stopping at the first
Dry runThe -n flag changes neither the output nor the exit code, because every run is report only
ExitsCompliant 0, non compliant 1, missing file 1

Usage

python3 main.py -c CONFIG_FILE -p POLICY_FILE [-n]
OptionWhat it does
-c, --configPath to the configuration file, YAML or JSON. Required.
-p, --policyPath to the JSON schema policy file. Required.
-n, --dry-runDescribed in the README as a dry run. Every run of this tool is report only, so the flag does not change the output or the exit code: a non compliant configuration still exits 1 with it.
-hShow help message and exit.

Stated limits

  • The name describes the job the tool was first pointed at, not the tool. The repository description claims it applies secure sysctl settings based on a target operating system profile; the code contains nothing sysctl specific, no operating system profile anywhere, and no application of anything. The configuration can be any YAML or JSON mapping and the policy any JSON schema.
  • Nothing is hardened in the sense of being changed: the tool never rewrites the configuration file. A non compliant configuration exits 1 so scripts can gate on the report.
  • Every failure is reported: validation collects the failures across the whole configuration rather than stopping at the first one.
  • The policy itself is never checked as a schema anywhere, so a malformed policy surfaces as one error string in the same list shape as a configuration violation, and the caller cannot tell policy is broken from configuration is broken. Both exit 1 with an errors list.
